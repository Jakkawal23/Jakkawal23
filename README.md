### 🧠 About Me

Software development used to be my job. Now it's my **hobby** — and honestly, it's more fun this way. 😎

These days my real life happens in hardware warehouses, on the mountains of **Doi Angkhang**, and around avocado trees.
So I do what any ex-developer does: **when something in real life is annoying, I write code until it isn't.**

- 🔩 Built tools for a hardware warehouse because counting nuts by hand is not a personality.
- 🏔️ Built websites for homestays on Doi Angkhang so tourists stop getting scammed by fake pages.
- 🥑 Wrote about avocados on the internet. Yes, really. More than once.
- 🤖 Trained AI models to read electric & water meters (because I didn't want to).
- 🎮 Made TikTok Live games where the chat plays Wordle together.
- 🎥 Also on YouTube as [Jakkawal Galaxy](https://www.youtube.com/c/jakkawalgalaxy), pretending to be wise and mysterious.

> *No deadlines. No sprint planning. Just me, coffee, and `git push` at 2 AM because I want to.*
